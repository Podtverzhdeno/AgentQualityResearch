# Agent Quality Research

Воспроизводимый стенд для сравнения двух конфигураций LangGraph-агента интернет-магазина. Оцениваются конечный ответ, траектория инструментов, затраты, устойчивость повторов и критические нарушения безопасности.

## Состав

- LangGraph-агент и инструменты LangChain;
- локальная SQLite-база со сбросом перед каждым запуском;
- baseline и candidate, различающиеся системным промптом;
- функциональные, траекторные, негативные и безопасностные сценарии;
- трассировка Langfuse при наличии настроенных переменных;
- решение ACCEPT / REVIEW / REJECT;
- JSON с прогонами и Markdown-отчет.

## Запуск

Рекомендуется Python 3.11-3.13.

    python -m venv .venv
    .venv\Scripts\activate
    pip install -e ".[dev]"
    python -m pytest
    aqr-sync-dataset
    aqr --repetitions 1 --limit 2
    aqr --repetitions 10

CLI показывает прогресс по каждому сценарию. Один запуск получает общий Experiment ID, который используется как Session ID в Langfuse. Трассы именуются по шаблону candidate/inventory-001/r01.

По умолчанию читается собственный файл .env, а если его нет — ..\LangfuseTest\.env. Значения ключей не копируются. Явный путь задается аргументом --env-file.

Для локального Langfuse сначала запустите Docker Desktop и compose из LangfuseTest\langfuse. Если Langfuse недоступен, локальный отчет все равно будет сформирован.

## Метод

Сначала применяются некомпенсируемые ограничения безопасности. Затем вычисляется взвешенная оценка из качества ответа, траектории, эффективности и надежности. Параметры находятся в configs/evaluation.yaml. Для итогового исследования зафиксируйте версии модели, набора, промптов и базы и выполните не менее 10 повторов.

Каждая трасса получает Scores answer_quality, trajectory_quality, efficiency, technical_success, safety_pass и violations. Отдельная evaluator-трасса experiment-summary содержит итоговое решение и агрегированные оценки.

Для бесплатной модели установлен общий лимит 12 запросов к модели в минуту и до 8 повторов после HTTP 429. Полный эксперимент поэтому может занять 25–40 минут. Не повышайте requests_per_minute без проверки лимита провайдера.

Команда aqr-sync-dataset идемпотентно создаёт набор agent-quality-research-v1 в разделе Langfuse Datasets. Повторный запуск обновляет те же элементы по детерминированным UUID и не размножает сценарии.
